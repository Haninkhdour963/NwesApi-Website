# NwesApi-Website

## Description
NwesApi-Website is a modern news aggregation platform designed to deliver the latest news articles from diverse sources in a centralized and user-friendly interface. The application enables effortless browsing and reading of news content, helping users stay informed with up-to-date information across multiple categories.

Built with contemporary web technologies, this project focuses on delivering a seamless and responsive experience on both desktop and mobile devices.

## Key Features
- **News Feed:** Continuously updated feed showcasing the latest news articles across various categories.
- **Source Filtering:** Easily browse news by specific sources or categories to personalize your news consumption.
- **Article Details:** Access detailed news articles featuring images, summaries, and publication dates.
- **Search Functionality:** Quickly find articles by keywords or topics of interest.
- **Responsive Design:** Optimized for smooth viewing on desktop, tablet, and mobile devices.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Framework:** Blazor Server (Modern web framework by Microsoft)
- **Data Integration:** RESTful APIs for fetching live news data
